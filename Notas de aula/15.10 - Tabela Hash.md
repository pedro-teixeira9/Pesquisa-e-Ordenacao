# Tabela Hash

## Conceito
A Tabela Hash é uma estrutura de dados que associa **chaves** a **valores**. O seu principal objetivo é permitir a busca, inserção e remoção de elementos de forma extremamente rápida.

## Como Funciona?
O núcleo dessa estrutura é a **Função Hash**.
1. Você fornece uma **chave** (ex: uma string ou um número).
2. A **Função Hash** processa essa chave e calcula um **índice** numérico (um número inteiro).
3. O **valor** correspondente é armazenado em um array na posição desse índice.

> **Exemplo:** Em linguagens como Python, as estruturas de dicionário (`dict`) são implementações diretas de tabelas hash. Em Java, se usa o `HashMap`.

## Pilares da Função Hash
Uma boa função hash precisa ter três características principais:
- **Determinística:** A mesma entrada deve sempre gerar o mesmo índice de saída.
- **Uniformidade:** Deve distribuir os dados de maneira equilibrada pelo array, evitando aglomerações.
- **Rapidez:** O cálculo matemático do índice deve ser leve e rápido de executar.

## Tratamento de Colisões
Uma colisão ocorre quando **duas chaves diferentes geram o mesmo índice** na função hash. Existem duas maneiras principais para resolver isso:

### 1. Encadeamento Separado
Cada posição do array principal não armazena apenas um elemento, mas sim um ponteiro para uma **Lista Encadeada**. Se houver colisão, o novo elemento é simplesmente adicionado ao final da lista daquele índice específico.

### 2. Endereçamento Aberto
Todos os elementos são armazenados no próprio array. Se um índice já estiver ocupado, o algoritmo procura a próxima posição vazia.
- **Sondagem Linear:** Procura no índice seguinte ($i + 1$, $i + 2$, etc.).
- **Sondagem Quadrática:** O salto entre os índices cresce de forma quadrática ($i + 1^2$, $i + 2^2$, etc.).
- **Duplo Hashing:** Uma segunda função hash é aplicada para calcular o tamanho do salto até encontrar um espaço vazio.

## Complexidade de Tempo (Big O)

| Operação | Caso Médio | Pior Caso (Muitas colisões) |
| :--- | :---: | :---: |
| **Busca** | $O(1)$ | $O(n)$ |
| **Inserção** | $O(1)$ | $O(n)$ |
| **Remoção** | $O(1)$ | $O(n)$ |

> **Nota:** O tempo constante $O(1)$ no caso médio é o que torna as tabelas hash uma das estruturas de dados mais utilizadas na Ciência da Computação, ideais para indexação de bancos de dados, criação de caches e contagem de frequências.
